# 安裝 Showtimes Radar Assistant

1. 在 Chrome 開啟 `chrome://extensions`。
2. 開啟右上角「開發人員模式」。
3. 點「載入未封裝項目」。
4. 選擇本 `chrome-extension` 資料夾。
5. 確認擴充功能顯示為「已啟用」。
6. 若你剛修改過監看條件或更新了篩選規則，請回到 `chrome://extensions` 直接按「重新載入」。
7. 保持擴充功能開啟，回到 Showtimes Radar 並登入秀泰，開始監看。

## 登入與購買流程

- 先在一般 Chrome 中登入秀泰官方網站，並保留該已登入分頁。
- 啟用 Showtimes Radar Assistant 後，當命中符合條件的場次時，擴充功能會接管該分頁。
- Assistant 會自動到票種頁設定票數、前往選位、選擇連號座位，並在套餐頁直接略過不加購。
- 最後進到訂單確認與付款頁時，仍需使用者自行確認訂單內容與完成付款。
- 每當要重新更新一次條件時，請重載一次 Showtimes Radar Assistant，讓新條件立刻套用，然後再重新執行登入與監看流程。

命中後擴充功能會在秀泰頁面右下角顯示紫色狀態訊息，自動設定票數、確認前往選位、選擇連號座位、按下一步，並在套餐頁不選商品直接點擊「確認訂單」。登入、Turnstile、最終訂單內容及付款仍由使用者操作。
