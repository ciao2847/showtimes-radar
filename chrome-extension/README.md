# 安裝 Showtimes Radar Assistant

第一次使用可先閱讀 [完整使用者手冊](../docs/USER_GUIDE.md)，依步驟下載桌面版、安裝小幫手並設定監看。

1. 在 Chrome 開啟 `chrome://extensions`。
2. 開啟右上角「開發人員模式」。
3. 點「載入未封裝項目」。
4. 選擇本 `chrome-extension` 資料夾。
5. 確認擴充功能顯示為「已啟用」。
6. 更新擴充功能程式後，回到 `chrome://extensions` 按「重新載入」，並重新整理秀泰分頁。
7. 修改名稱、日期、張數等監看條件只需在 Radar 按「更新條件」。

## 登入與 API 選位

- 在一般 Chrome 登入秀泰官方網站，保留已登入分頁。
- 在 Radar 輸入特別場名稱（例如「泥面人」）、日期與張數並開始監看，網址可留空。
- 查到空位足夠的場次後，Assistant 在該秀泰分頁沿用登入狀態，呼叫官方 API 取得票種與座位圖、建立購物車並保留座位。
- 優先連號，也接受符合影城規則的分散座位；維持設定張數。成功後開啟訂單確認頁，使用者自行確認並付款。
- 無登入、需特殊票種資訊或已有未完成訂票時會停止並在 Radar 顯示原因。保留結果不明時先到秀泰確認目前訂票，避免重複建立。

`scripting` 權限用來在秀泰分頁執行 API 流程；登入憑證保留在秀泰頁面，不傳回本機 Radar。擴充功能不會自動付款。
