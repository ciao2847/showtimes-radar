# Showtimes Radar 1.0.5 — macOS Apple Silicon

修正保留座位後退回「所有影城」、無法進入訂單確認頁的問題。

- 掃描快取缺少電影分級 `program.rating` 時，改從秀泰官方 API 模組取得完整資料，避免確認頁將購物車判為無效並清除。
- 保留成功後寫入官方座位保留標記，並檢查確認頁是否成功載入；失敗時顯示錯誤並保留訂票防重複狀態。
- 擴充功能重載時不重跑已完成指令，重複回報也不覆蓋原結果。

## 安裝

1. 關閉舊版 App，以 1.0.5 DMG 取代「應用程式」中的 Showtimes Radar。
2. 更新 Chrome 擴充功能至 1.0.5，重新載入並確認秀泰登入。
3. 只在用來訂票的 Chrome 使用者設定檔啟用擴充功能，避免不同設定檔同時接收指令。

## 驗證與發布範圍

- 53 項自動測試通過。
- 已在 macOS Apple Silicon 上，透過完整雷達掃描與擴充功能流程，驗證可進入官方訂單確認頁並顯示付款方式；未執行付款。
- 本次發布 macOS Apple Silicon DMG、ZIP、Chrome 擴充功能與下載中繼資料。
- Windows 尚待另外測試，本次不發布 Windows 安裝檔；Intel Mac 未經本次實機驗證，也不提供新安裝檔。
