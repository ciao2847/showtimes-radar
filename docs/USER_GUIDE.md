# 秀泰特別場搶票雷達｜使用者手冊

這份手冊適合第一次使用、沒有程式背景的人。使用已打包的桌面版即可，**不需要安裝 Node.js、輸入指令或修改程式**。

雷達會定時尋找符合條件的秀泰特別場，空位足夠時自動選票、選位與保留座位，再開啟秀泰訂單確認頁。**最後確認訂單與付款要由你完成；看到「座位已保留」還不代表購票完成。**

## 1. 下載與安裝

準備一台 Mac 或 Windows 電腦、Google Chrome，以及可登入的秀泰會員帳號。

開啟 [下載頁面](https://github.com/ciao2847/showtimes-radar/releases/latest)，找到 **Assets（下載檔案）**。若清單未展開，點一下 Assets。

以下檔名以 v1.0.2 為例，之後版本號可能不同，請依電腦類型選擇：

| 你的電腦 | 要下載的檔案 |
| --- | --- |
| Windows 64 位元 | `Showtimes-Radar-Setup-1.0.2.exe` |
| Mac，Apple 晶片（M1、M2、M3 等） | `Showtimes.Radar-1.0.2-arm64.dmg` |
| Mac，Intel 處理器 | `Showtimes.Radar-1.0.2.dmg` |
| 所有人另外下載 | `showtimes-radar-assistant-chrome-extension.zip`（Chrome 小幫手） |

Mac 可從左上角 Apple 選單 →「關於這台 Mac」查看晶片或處理器。下載頁面的 `Source code` 是程式原始檔，一般使用者請選上表的安裝檔。

### Windows

1. 下載 `.exe` 安裝檔。
2. 先關閉舊版 Showtimes Radar，再連按兩下安裝檔，依畫面完成安裝。
3. 從開始功能表開啟 **Showtimes Radar**。

### Mac

1. 下載適合晶片類型的 `.dmg`。
2. 連按兩下開啟，將 **Showtimes Radar** 拖到「應用程式」。
3. 從「應用程式」開啟 Showtimes Radar。
4. 此版本未設定 Apple 開發者簽章。若首次開啟受到系統阻擋，可先在 Finder 對 App 按右鍵 →「打開」；若仍受阻，查看「系統設定 → 隱私權與安全性」中的提示，只在確認是從本專案下載後允許開啟。

## 2. 安裝 Chrome 小幫手

小幫手名稱是 **Showtimes Radar Assistant**，負責在已登入的秀泰分頁協助選票與保留座位。第一次必須手動安裝。

1. 將剛下載的 `showtimes-radar-assistant-chrome-extension.zip` 解壓縮。Windows 可按右鍵 →「解壓縮全部」；Mac 可連按兩下。
2. 把解壓縮後的資料夾放在固定位置，例如「文件／Showtimes Radar Assistant」。**安裝後不要刪除或移動這個資料夾。**
3. 開啟 Google Chrome，在上方網址列輸入 `chrome://extensions`，按 Enter。
4. 開啟右上角的「開發人員模式」。
5. 按「載入未封裝項目」，選擇解壓縮後、裡面有 `manifest.json` 的資料夾。若外面還包了一層資料夾，請再往內找。
6. 確認清單中出現 **Showtimes Radar Assistant**，且開關為開啟狀態。

請選擇解壓縮後的資料夾，不要選 ZIP 壓縮檔。此步驟只需第一次安裝時做；更新方式見[第 8 節](#8-更新程式)。

## 3. 登入秀泰

1. 開啟 Showtimes Radar。
2. 按右上角「登入秀泰」。
3. 在開啟的 Chrome 秀泰頁面手動完成會員登入；若有驗證碼或人機驗證，請自行完成。
4. **保留已登入的秀泰分頁，不要關閉**，並確認是在安裝小幫手的同一個 Chrome 使用者中登入。
5. 如有先前尚未完成的訂票，請先到秀泰處理，再開始新的監看。

雷達右上角顯示「已開啟一般 Chrome」只代表已開啟瀏覽器，並不代表會員登入成功。請直接在秀泰網站確認會員登入狀態。

## 4. 設定想看的場次

左側「01 / 目標設定」是填寫條件的地方。雷達搜尋的是秀泰公開的**特別場**資料，請以官方公布的特別場名稱為準。

| 畫面欄位 | 怎麼填 |
| --- | --- |
| 特別場名稱搜尋 | 必填。輸入活動或片名關鍵字，例如「泥面人」。不必輸入網址或場次編號。 |
| 日期 | 必填。填「電影放映日」，不是開賣日；開始前再核對一次。 |
| 時間（可留空） | 電影開演時間，例如 `19:30`。留空代表不限制時間。 |
| 影城（可留空） | 輸入官方顯示的影城名稱或片段，例如「大巨蛋」。留空代表不限制影城。 |
| 影廳 / 版本（可留空） | 例如 `ULTRA 4DX`。留空代表不限制影廳或版本。 |
| 票種名稱關鍵字 | 預設「全票」。想買特別場套票時，填入能明確辨識該票種的名稱。 |
| 希望張數 | 選 1～6 張，代表需要幾個電影座位。 |
| 開始監看時間（可留空） | 填希望開始監看的日期與時間，例如開賣時間；留空即立刻開始。請確認電腦日期、時間與時區正確。 |
| 掃描間隔 | 多久檢查一次，預設 15 秒；初次使用可保留預設值。 |

**留空的影城、時間與影廳代表都可以接受。** 若你只想去某間影城，請務必填入，避免自動保留其他影城的座位。

### 第一次設定範例

假設你想看「泥面人」，只接受大巨蛋影城、晚上 19:30 的場次，買 2 張：

1. 特別場名稱搜尋：填「泥面人」。
2. 日期：選官方公布的放映日。
3. 時間：填 `19:30`。
4. 影城：填「大巨蛋」。
5. 影廳 / 版本：沒有偏好就留空。
6. 票種名稱關鍵字：一般全票保留「全票」；若活動只賣套票，依官方名稱填寫。
7. 希望張數：選「2 張」。
8. 開始監看時間：要立即監看就留空；要等開賣再開始就填開賣日期與時間。
9. 掃描間隔：保留「15 秒」。

以上只是填寫示範，不表示這個活動實際有該場次。

### 想買套票時

可填完整票種名稱，或能唯一辨識的片段，例如 `DVA特別場套票`。明確指定後，程式不會自行改買其他名稱的票種。

「希望張數」仍填電影座位數。例如雙人套票需要 2 個座位，就選 2 張，程式會換算套票份數。若票種不明確、需要券號或銀行資格、套票品項售完，程式可能停止，請依訊息手動處理。最後務必在秀泰訂單頁核對票種、份數、內容與金額。

## 5. 開始監看與完成付款

1. 核對條件，尤其是影城、放映日期、票種與張數。
2. 按「開始監看並自動選位」。**這個按鈕會啟用自動訂票流程**；找到足夠空位時會嘗試保留座位。
3. 查看右側「02 / 即時雷達」的執行進度、掃描次數與場次清單。
4. 保持電腦開機且不休眠、網路連線正常、Radar 與 Chrome 開著，並保留已登入的秀泰分頁。
5. 出現「座位已保留」後，到 Chrome 的秀泰訂單確認頁，核對影城、日期、時間、座位、票種與總金額。
6. 在秀泰頁面顯示的期限內完成確認與付款，再到秀泰確認訂單是否成立。

空位不足、滿場或空位數未知時，雷達會繼續等候。空位總數足夠仍可能選位失敗，因為其他人也在訂票，且座位必須符合影城規則。

**程式優先選連號，也可能選分開的座位；不能保證連座，目前沒有指定排數或座位的設定。** 若你只接受連座，請特別注意此行為，並在付款前核對。

### 如何看進度

| 畫面情況 | 代表什麼、接下來怎麼做 |
| --- | --- |
| 尚未開始 | 尚未啟動監看，先填條件並按開始。 |
| 等待開始時間 | 已設定排程，保持程式開著。 |
| 搜尋或等待足夠空位 | 正在找符合條件的場次或等待釋票。 |
| 連線、取得票種、挑選座位、建立訂票、保留座位、確認金額 | 正在自動訂票，查看目前步驟即可。 |
| 座位已保留／等待確認付款 | 切換到秀泰頁面，核對並完成付款。 |
| 需要處理 | 讀取目前步驟下方的錯誤訊息及「執行紀錄」，依原因處理。 |

「執行紀錄」會顯示各步驟與時間，最近的紀錄在上方。場次旁的「手動開啟秀泰」可開啟該場次頁面，但不代表已完成保留。

如果設定未來的開始時間，程式會提前約 8 秒準備票種資料，這時不會保留座位。看到「已沿用預載票種」是正常訊息，不需要額外操作。

## 6. 更改條件與停止監看

- **更改條件：** 修改左側欄位後，按「更新條件」才會套用。只改文字不會更新正在執行的監看。
- **停止監看：** 按「停止」。這會停止後續掃描；若訂票已在進行，仍須到秀泰查看結果。
- **取消訂票：** 停止監看不會取消已保留的座位或既有訂單，請到秀泰網站處理。
- **結束使用：** 先停止監看，再結束 Showtimes Radar。Mac 若要完全退出，請使用 App 選單的「結束」或按 `Command + Q`。

程式關閉或電腦重新啟動後，請重新設定並啟動監看，不要假設上次的排程仍在執行。

## 7. 常見問題

### 找不到符合條件的場次

先比對官方特別場名稱與放映日期。可先放寬「時間、影城、影廳」來查找，但因為空位足夠時會自動訂票，**只留下你願意購買的範圍**。若官方還沒公布場次，可能暫時查不到。

### 已登入，卻提示找不到登入分頁或無法連線

確認 Chrome 開著、秀泰分頁仍在，且該 Chrome 使用者已安裝並啟用小幫手。重新整理秀泰分頁並確認仍登入；若剛更新小幫手，請到 `chrome://extensions` 按重新載入，再重新整理秀泰頁面。

### 安裝小幫手時顯示找不到資訊清單

通常是選到錯誤層級或尚未解壓縮。請選擇裡面直接看得到 `manifest.json` 的資料夾，再試一次。

### 有空位，為什麼沒有成功保留？

空位是當下的總數，不保證連號，也不保證訂票時仍有票。可能是空位不足希望張數、座位配置不符合規則，或票種條件無法滿足。先看執行紀錄中的原因。

### 顯示票種有歧義、需要資格或套票無法購買

到官方頁面確認可購買票種與資格，將「票種名稱關鍵字」改成更明確的名稱。需要券號、銀行資格或其他人工確認的票種，請改由秀泰頁面手動完成。

### 顯示已有未完成訂票、保留逾時或結果不明

**先到秀泰查看目前訂票或訂單，不要立刻反覆重試。** 可能已有保留中的座位。確認或處理完現有訂票後，再決定是否重新監看。

### 沒有聲音，或沒有自動出現付款頁

以 Radar 的進度與 Chrome 秀泰頁面為準，請持續查看畫面。若顯示座位已保留，先切換到已登入的秀泰分頁查看訂單；不要只因沒聽到通知就重新開始訂票。

### 顯示查詢失敗或網路錯誤

先確認網路與秀泰網站是否正常。監看中的查詢錯誤會在下次掃描重試；若錯誤發生在建立訂票或保留座位，則先依上一題查看秀泰現有訂票。

### 程式無法啟動

先關閉既有的 Showtimes Radar，再重新開啟。若仍失敗，記下「啟動失敗」視窗中的完整訊息。回報問題時可附上作業系統、程式版本、操作步驟與錯誤畫面；截圖請遮住會員資料、訂單個資及付款資訊。

## 8. 更新程式

1. 先停止監看，並到秀泰確認有沒有尚未完成的訂票。
2. 完全退出 Showtimes Radar。
3. 到[下載頁面](https://github.com/ciao2847/showtimes-radar/releases/latest)下載新版桌面安裝檔與小幫手 ZIP。
4. 安裝新版桌面程式。
5. 將新版小幫手 ZIP 解壓縮，更新原本固定位置的小幫手資料夾內容；若改用新資料夾，請在 Chrome 移除舊小幫手，再「載入未封裝項目」選新資料夾。
6. 在 `chrome://extensions` 找到小幫手，按卡片上的重新載入按鈕。
7. 重新整理秀泰分頁並確認登入，再開啟 Radar 重新設定監看。

桌面程式與 Chrome 小幫手都需要更新。只更新其中一個，可能造成連線或訂票流程異常。

## 每次使用前檢查

- [ ] Radar 已開啟。
- [ ] Chrome 小幫手已啟用。
- [ ] 同一個 Chrome 使用者中，保留已登入的秀泰分頁。
- [ ] 放映日、影城、時間、票種與張數都正確，能接受分散座位。
- [ ] 已按開始，或修改後已按「更新條件」。
- [ ] 電腦不休眠、網路穩定，自己能及時完成付款。

本工具不會代替你完成登入、人機驗證或付款，也不能保證搶到票。實際保留狀態、付款期限與購票結果，請以秀泰網站為準。
